41. [중]
S에서 A까지의 실제 이동 비용이 6이고 A에서 목표 G까지의 휴리스틱 비용이 11일 때, S에서 A를 거치는 경로의 평가 함숫값을 고르시오.
정답: 3번 — 17
해설: 평가 함숫값 f = g + h = 6 + 11 = 17이다. (02_02 참고)
42. [중]
S에서 B까지의 실제 이동 비용이 8이고 B에서 목표 G까지의 휴리스틱 비용이 10일 때, S에서 B를 거치는 경로의 평가 함숫값을 고르시오.
정답: 1번 — 18
해설: 평가 함숫값 f = g + h = 8 + 10 = 18이다. (02_02 참고)
43. [상]
S에서 B까지 8, B에서 C까지 6이 들어 실제 이동 비용 합이 14이고, C에서 목표 G까지의 휴리스틱 비용이 5일 때, S에서 C를 거치는 경로의 평가 함숫값은 얼마인가요?
정답: 1번 — 19
해설: 평가 함숫값 f = g + h = (8+6) + 5 = 19이다. (02_02 참고)
44. [상]
S→A(6), S→B(8), A→B(6), B→C(6), C→G(5), B→G(12)의 실제 이동 비용과 각 노드에서 목표 G까지의 휴리스틱 비용(S:16, A:11, B:10, C:5)이 주어졌을 때, A* 알고리즘으로 찾은 S에서 G까지의 최단 경로는 무엇인가요?
정답: 2번 — S → B → C → G
해설: 각 경로의 실제 비용을 비교하면 S→B→C→G(8+6+5=19)가 S→B→G(8+12=20)보다 짧아 최단 경로가 된다. (02_02 참고)
